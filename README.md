# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates the simple interest earned on a principal amount based on the interest rate and time period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal** = Initial amount of money
* **Rate** = Rate of interest per year
* **Time** = Time period in years

## Example

If the principal amount is **$1000**, the interest rate is **5%**, and the time is **2 years**:

**Simple Interest = (1000 × 5 × 2) / 100 = $100**

Therefore, the simple interest is **$100**.

## Features

* Easy to use
* Calculates simple interest quickly
* Requires principal amount, interest rate, and time
* Beginner-friendly project
